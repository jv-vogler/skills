# frontend

Frontend architecture for React codebases.

## Skills

### `frontend:architecture`

A four-layer architecture — `infrastructure` → `domain` → `view` → `routes` — where everything
the app *means* lives in a layer neither the network nor React can corrupt. Covers dependency
rules, file layout, naming conventions, and a review checklist, with reference files carrying
full code for a vertical slice, flows and forms, typed errors, and the generic helpers, so
adopting it requires installing nothing.
