# pr

Pull request skills: review the change, explain it.

## Skills

### `pr:local-review`

Reviews a PR locally and writes the findings to a foldable markdown file in the repo root —
nothing is posted to GitHub. Judges correctness (real bugs, traced into the code) and design
(should the change exist, is it consistent, is it breaking).

### `pr:write-description`

Writes PR descriptions that explain what changed and why, instead of narrating the diff file by
file.

## Install
